## 🔒 6. How Security Works (Explained Simply for Non-Tech Owners)

You don't need a computer science degree to understand how your academy and your students' data are protected. Think of your platform's security like a **modern bank branch**:

```

│    (Gatekeeper)       │ Blocks unauthorized people before they enter.  │
├───────────────────────┼────────────────────────────────────────────────┤
│ 🔑 Digital Badges     │ Students only get student badges. Staff only   │

├───────────────────────┼────────────────────────────────────────────────┤
│ 💰 Fraud Protection   │ Fee entries cannot accept negative numbers,    │
│    (Ledger Integrity) │ zero amounts, or fake transaction statuses.    │
├───────────────────────┼────────────────────────────────────────────────┤
│ 📦 X-Ray Inspection   │ Every photo uploaded is scanned for file type  │
│    (Safe Uploads)     │ and size so malicious files can never enter.   │
└───────────────────────┴────────────────────────────────────────────────┘
```

### Simple Answers to Common Security Questions:
* **Can a student sneak into the Admin section?**
  * **No.** If a student tries to type `/admin` in the browser, the system immediately blocks them and sends them back to their student dashboard.
* **Can an instructor see the institute's financial ledger?**
  * **No.** Only accounts with the `accountant` or `admin` role have permission to see fee collections and profit/loss reports.
* **Can an outsider upload viruses through the image upload?**
  * **No.** The system checks that the uploader is logged in, validates that the file is an actual picture (`.jpg`, `.png`, `.webp`), and rejects any file larger than 5MB.
* **Are passwords safe?**
  * **Yes.** Passwords are encrypted using cryptographic standards. Even the database administrator cannot see a student's plaintext password.

### For the Admission Counselor / Admin:
1. **Check New Applications**: Go to `/admin/users` daily to view new student registrations. Call/WhatsApp them to confirm admission and click **"Approve"**.
